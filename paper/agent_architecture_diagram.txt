============================================================================
KEY INSIGHTS
============================================================================

1. UNCONSTRAINED EVOLUTION (G2-G4):
   ✓ Achieves highest raw capability gains (+0.28)
   ✗ Catastrophic security drift (32% violations)
   ✗ Severe gaming behaviors (+0.55 on probes)
   ✗ Substantial forgetting (retention drops to 81%)

2. STATIC VERIFICATION (G5):
   ✓ Blocks syntactic exploits (test mocking, patching)
   ✓ Low computational overhead
   ✗ Cannot detect functional gaming (hardcoded shortcuts)

3. BEHAVIORAL ROLLBACK (G7):
   ✓ Maintains capability gains (+0.24)
   ✓ Zero security violations
   ✓ Low gaming (+0.016)
   ✓ Strong retention (96%)
   ✓ Deployable in production
   ✗ Higher computational cost

4. THE TRILEMMA:
   Cannot maximize ALL of: capability, security, gaming prevention, retention
   G7 successfully navigates the Pareto frontier

============================================================================
DEPLOYMENT RECOMMENDATION
============================================================================

Production systems should use:
  G7 (Rollback Verification) - deployable, balanced, proven

Avoid:
  G4 (Unconstrained) - dangerous, 32% violation rate
  G7* (Oracle) - not deployable (requires hidden tests)

Research baseline:
  G1 (Frozen) - control condition for comparisons
